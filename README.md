# Task Manager Fullstack

##  Descrição
Aplicação full stack para gerenciamento de tarefas, permitindo criar, listar, excluir e marcar tarefas como concluídas.

##  Tecnologias utilizadas

### Frontend
- Angular
- TypeScript
- HTML / CSS

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server

##  Funcionalidades
- Criar tarefa
- Listar tarefas
- Excluir tarefa
- Marcar como concluída
- Exibir data de criação

##  Como executar

### Backend
``bash
- cd TaskApi
- dotnet run

### Frontend

- cd task-front
- ng serve
